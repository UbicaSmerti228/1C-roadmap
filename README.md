# 1С Roadmap

Интерактивная карта для изучения разработки на «1С:Предприятии 8» с нуля до первой работы и сертификатов «1С:Профессионал» и «1С:Специалист» по платформе.

**Открыть: https://ubicasmerti228.github.io/1C-roadmap/**

## Что внутри

Карта состоит из восьми этапов. Сквозной проект «Учёт магазина» растёт вместе с ними — от пустой базы до конфигурации с проведением, отчётами, бухгалтерией, расчётом зарплаты и интеграциями.

| № | Этап | Что собираешь |
|---|------|---------------|
| 0 | Абсолютный ноль | учебная платформа, первая база, основы учёта |
| 1 | Встроенный язык | v0.1 — общий модуль расчётов |
| 2 | Объекты конфигурации | v0.2 — справочники и документы |
| 3 | Регистры, проведение и запросы | v0.3 — остатки, продажи, себестоимость |
| 4 | Формы, интерфейс и отчёты | v0.4 — права, отчёты на СКД, печать |
| 5 | Бухгалтерия, расчёт и бизнес-процессы | v0.5 — проводки, зарплата, согласование |
| 6 | Типовые решения, интеграции и администрирование | v1.0 — HTTP-сервис, расширение, Git |
| 7 | Сертификация и первая работа | витрина проекта, экзамены, оффер |

Каждая тема проходится в пять шагов: главный материал, дополнительные материалы, задание, тест, самопроверка «Умеешь».

На сайте есть список и граф тем, план на сегодня, прогноз даты финиша, повторение ошибок из тестов, экзамен по каждому этапу и поиск по карте.

Прогресс хранится только в браузере. Чтобы не потерять его, время от времени скачивай копию через меню.

**«1С:Специалист» по платформе** — практический экзамен на 3–5 часов в каркасной конфигурации; нужен сертификат «1С:Профессионал». Блоки билета: оперативный учёт, бухгалтерский учёт, периодические расчёты и общие задачи (формы, интерфейс, бизнес-процессы). Им соответствуют этапы 3–5 и узел «1С:Специалист по платформе» этапа 7.

Тесты в карте написаны по официальной документации и методическим материалам, но это не копия экзаменационных вопросов. Для самого экзамена используй официальный комплект вопросов и сборник задач (ссылки в этапе 7).

## Запуск у себя

Сборки нет. Открой `index.html` в браузере или подними любой статический сервер:

```
python3 -m http.server 8000
```

## Как править карту

Формат записи темы описан в комментарии в начале `data.js`.

Прогресс учеников привязан к id и к номерам пунктов, поэтому:

- **id узлов и тем не меняй.** Порядок тем и узлов менять можно.
- **Новые вопросы теста добавляй только в конец.** Повторение ошибок ссылается на номер вопроса.
- **Пункты «Умеешь», чек-листов и milestone не удаляй и не переставляй.** Отметки хранятся по номеру пункта: текст правь на месте, новые пункты добавляй в конец.
- **Если тема переезжает в другой узел,** добавь пару «старый ключ → новый» в `RENAME` в конце `data.js`, тогда прогресс перенесётся.
- **Копии видео** на Rutube или VK Видео записывай в `MIRROR` (id видео на YouTube → ссылка). Подходят только официальные каналы авторов, не перезаливы.

## Проверки

```
python3 scripts/validate.py      # структура data.js
python3 tests/run.py             # тесты сайта в браузере без окна
python3 scripts/check_links.py   # живы ли ссылки, идёт несколько минут
```

`tests/run.py` открывает сайт в настоящем браузере (Firefox или Chromium) и проходит по нему: раскрывает темы, решает тесты, сдаёт экзамен этапа, проверяет экспорт и импорт. Сами тесты лежат в `tests/tests.js`.

`validate.py` и тесты сайта запускаются в GitHub Actions на каждый push и pull request, `check_links.py` — первого числа каждого месяца и вручную.

Сайты с защитой от ботов могут отвечать на автоматическую проверку кодом 403. Такие ссылки попадают в список «проверь руками» и сборку не роняют.

## Поисковый индекс

`search-index.js` хранит разделы статей и главы видео, по которым работает поиск. После добавления статей или видео в `data.js` достраивай индекс:

```
python3 scripts/build_search_index.py
```

Скрипт скачивает только новые материалы и убирает записи об удалённых. Флаг `--all` пересобирает индекс с нуля. Пока индекс не собран, поиск работает по темам, «сути» и тестам карты.
